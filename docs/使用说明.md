# 寻迹助手 使用说明

面向拿到安装包的使用者。它是一个装在本机的桌面程序：你用自然语言提问，它会按问题内容自动去查你登记过的代码库、导入的飞书聊天记录、Confluence 规范、MasterGo 设计稿等资料，回答末尾会标明这次实际查了哪些来源、依据是什么。所有资料源都是只读，不会改动你的任何文件。

## 一、安装

1. 双击 `寻迹助手-<版本>-安装.exe`。
2. 安装位置默认在你的用户目录下，不需要管理员权限；想装到别处可以在向导里改。
3. 勾选"创建桌面快捷方式"（默认勾选），完成。

安装过程要复制一万多个小文件，一般需要几分钟，慢是正常的。

**首次启动**会在窗口里显示"首次启动，正在初始化"，大约一分钟，之后每次都是秒开。这一步只在第一次和升级后发生。

## 二、第一次使用要做的两件事

**1. 填 DeepSeek API 密钥。** 没有密钥无法对话，提问时会提示"API 密钥缺失"。

- 打开设置，进入"模型"。
- 找到 DeepSeek 提供方，点"编辑"，在"API 密钥"里粘贴你的密钥，保存。

**2. Agent 预设选"标准模式"。** "极简模式"会屏蔽本工具的资料检索能力，切换后什么都查不到。

## 三、界面在哪

- **溯源配置**：左侧栏"新会话"按钮下方。这里能看到每个资料源的启用状态，也在这里填写配置和上传文件。
- **会话内查看**：聊天时点右侧栏的"+"，可以打开同名标签，边聊边看状态。
- **回答尾部**：每条回答下面有"实际检索"一行，列出这次真正查过的来源；有具体依据时还会列出"依据"，比如文件路径、会话名和发送人。没查到依据时它会明说，不会编。

## 四、配置资料源

打开"溯源配置"，顶部选一个资料源，填写后点"保存到本机 .env"。**除飞书对话文件上传外，所有配置改动都要关闭窗口重新打开才生效。**

### 代码库（推荐先配）

让它能读你本机的项目代码。

- 填项目根目录的绝对路径，例如 `C:\workspace\my-project`；多个项目用英文分号隔开。
- 保存并重启。首次启动会为项目建索引，之后改了代码会自动跟进，不用再重启。
- 自动跳过依赖目录、构建产物、`.git`、`.env`、证书和私钥文件。

### 飞书对话导入

让它能查飞书里的聊天记录。不连接飞书账号，文件只存在你本机。

第一次启用：

1. "启用对话导入"选"启用"，保存，重启一次。

之后导入记录，随时可做，不用重启：

1. 在飞书客户端里悬停某条消息，点"…"→"多选"，用"选择以下消息"一次最多勾 100 条，点"导出到文档"。
2. 打开生成的云文档，右上角"…"→"下载为"→ Markdown。带图片的会下载成 zip。
3. 把 zip 或 md 拖到"溯源配置 → 飞书对话导入"下方的上传区。

上传后列表里会显示状态："待检索时索引"表示还没用到，"已索引"表示可以查了，"解析失败"会给出原因，通常是文件不是飞书导出的格式。同一个会话分几次导出会自动合并去重。单个文件上限 64 MB。图片只记数量，附件只记文件名，需要看图请回原会话。

### Codex / Claude 历史

如果你在本机用 Codex 或 Claude Code，可以让它查你之前和 AI 聊过的方案、结论和操作记录。

- 填 `codex`、`claude` 或 `codex,claude`，保存并重启。
- 只读会话记录和项目记忆，不读密钥、日志。

### 飞书文档、MasterGo、Confluence

这三个需要企业侧的凭据，卡片上有获取步骤和官方链接。填好保存并重启后，首次实际检索时才会验证凭据是否正确。

Confluence 需要本机额外安装 `uv` 工具，没有的话这个来源启动不了，找管理员要一下。

### 清除某项配置

已保存的项旁边有"清除此项"按钮，点它，再点保存，重启后生效。

## 五、怎么提问

直接问就行，不用指定去哪查。它按问题内容判断：

- "订单退款接口在哪个文件，参数是什么" → 查代码库
- "上周张三在群里说的需求口径是什么" → 查导入的飞书对话
- "之前我们讨论过的方案为什么改了" → 查 Codex / Claude 历史
- "内部规范里对日志格式怎么要求" → 查 Confluence
- "这个页面设计稿的间距和颜色" → 查 MasterGo

看回答尾部的"实际检索"确认它查的是你想要的来源。它只会查已启用的来源，没启用的不会去猜。

## 六、数据在哪，安不安全

- 配置、密钥、会话、索引和导入的文件都在 `%LOCALAPPDATA%\寻迹助手` 下，和程序目录分开。
- 所有资料源都是只读，不会修改代码、飞书、Confluence 或设计稿。
- 导入的飞书记录和代码索引只存本机，不上传到任何地方。
- 提问时，你的问题和检索命中的片段会发给模型服务；哪些会发、哪些不会、怎么改成内网模型，见 `隐私说明.md`。
- 关闭窗口就会结束后台服务，不会留常驻进程。

## 七、升级、卸载

- **升级**：直接运行新版安装包覆盖安装，配置和数据都会保留。升级后首次启动会重新初始化一次，约一分钟。
- **卸载**：控制面板卸载即可，用户数据会保留。
- **彻底清除**：卸载后手动删除 `%LOCALAPPDATA%\寻迹助手` 目录。

## 八、常见问题

**改了配置没生效**：关闭窗口重新打开。只有上传飞书文件不需要重启。

**提示"API 密钥缺失"**：见第二节，去设置的"模型"里填 DeepSeek 密钥。

**提示"没有可用端口"**：说明已经有一个实例在运行，或者端口被别的程序占了。先关掉已打开的窗口再试。

**首次启动提示"初始化失败"**：多半是安装刚完成、杀毒软件还在扫描新文件，程序会自动重试一次；仍失败就关闭窗口重新打开，一般第二次就好了。

**不要把 exe 单独复制到别处运行**：它依赖旁边的 app 和 runtime 目录，挪走会提示找不到脚本。要放桌面请用安装时创建的快捷方式。

**启动失败**：窗口里会直接显示原因和日志路径。日志在 `%LOCALAPPDATA%\寻迹助手\logs`，把最新的 `start-*.err.log` 或 `setup-*.err.log` 发给维护的人。

**上传的飞书文件显示"解析失败"**：确认是按第四节的步骤从飞书"导出到文档"再"下载为 Markdown"得到的文件，不是自己复制粘贴的文本。

**回答说没有找到依据**：检查"溯源配置"里对应来源是不是"已启用"；代码库要确认路径填对且已重启过。
