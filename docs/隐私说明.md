# 寻迹助手 隐私说明

一句话：资料留在本机，离开本机的只有"你的提问"和"检索命中的片段"，而且只发给你自己选定的模型服务和你自己配置的资料源服务商。所有资料源都是只读。

## 一、留在本机的

安装版的数据目录是 `%LOCALAPPDATA%\寻迹助手`，开发版是项目内的 `.dsh/` 与 `.env`。里面有：

| 内容 | 位置 | 说明 |
|---|---|---|
| 资料源凭据 | `.env` | 页面保存时写入，不回显、不存浏览器 |
| 模型密钥 | `.dsh\.credentials.yaml` | 由 DSH 设置页写入 |
| 会话记录 | `.dsh\sessions` | 你和助手的对话 |
| 本地知识库 | `.dsh\knowledge.sqlite` | |
| 导入的飞书文件 | `.dsh\imports` | 原文件加索引 |
| 代码库与历史归档索引 | `.dsh\codebase-index`、`.dsh\conversation-archive-index` | 只含被登记项目与本机会话的内容 |
| 启动日志 | `logs\` | 见第四节 |

配置接口只监听本机 `127.0.0.1`，只接受来自本机页面的请求，只允许白名单变量。打包分发时不会带上以上任何数据，打包脚本会逐文件复查。

## 二、会离开本机的

### 1. 发给模型服务

默认模型服务是 DeepSeek 官方接口。每次提问，以下内容会作为请求发出：

- 你输入的文字、拖入对话的截图和文件。
- 系统提示词，包括资料路由规则。
- 每次工具调用返回给模型的内容，也就是"检索命中的片段"：
  - 代码库：每条命中约 700 字符的片段；读文件时最多 400 行。
  - 飞书对话：每条命中约 600 字符，读上下文时是命中消息前后各几条的正文。
  - Codex / Claude 历史：每条命中约 800 字符；读取单条时最多 4200 字符。
  - Confluence 页面正文、飞书文档内容、MasterGo 设计结构数据。

索引文件、导入的原始文件、`.env`、原始会话文件本身不会发送，只有被检索命中的那部分内容会。

### 2. 发给资料源服务商

只在你启用了对应资料源、且提问触发检索时发生，由本机子进程直接请求，不经过任何中转：

- MasterGo：文件与图层 ID、你的个人令牌，发往 mastergo.com。
- 飞书文档 / 知识库：搜索关键词、应用凭据，发往飞书开放平台。
- Confluence：CQL 查询、只读账号，发往你填写的 Confluence 地址。

代码库、Codex / Claude 历史、飞书对话导入这三个资料源完全在本机运行，不访问任何网络。

### 3. 首次初始化与按需下载

首次启动会从 npm 仓库下载本地知识插件；MasterGo 与飞书的官方 MCP 在第一次使用时由 npx 下载；Confluence 由 uvx 下载。这些只传输包名与版本，不含你的数据。

### 4. 关于 DSH 本身

本项目不修改 DSH 核心。对当前固定版本的代码检查，模型请求只发往 DeepSeek 接口，未发现第三方统计或崩溃上报的域名；本机会生成一个匿名 ID 文件。升级 DSH 版本时会重新复核这一点。

## 三、凭据怎么存、怎么传

- 模型密钥由 DSH 保存在数据目录内，不进入 `.env`。
- 资料源凭据保存在 `.env`，页面保存后不再回显。
- 传给 MCP 子进程时，MasterGo 与 Confluence 走环境变量，不出现在命令行。飞书的 App ID 与 App Secret 目前以命令行参数传给官方 MCP，本机其他进程可以从进程列表看到，这是已知的待改进项。
- 第三方 MCP 一律经本机只读代理启动，只暴露白名单工具，模型无法调用它们自带的写操作。

## 四、日志里有什么

`logs\start-*.out.log` 含本机服务地址，地址里带一次性会话 token；`setup-*.log` 与 `*.err.log` 只有启动过程与错误信息。需要把日志发给别人排障时，优先发 `err` 日志。

## 五、想进一步减少外发，可以这样做

- **换成内网模型**：DSH 设置 → 模型 → 添加提供方，填内网 vLLM 或 Ollama 的 OpenAI 兼容地址并设为默认。此后第二节第 1 条的全部内容只到内网。
- **只启用需要的资料源**：没启用的来源不会被检索，也不会有任何请求。
- **代码库只登记必要的项目**：`.env`、证书、私钥、常见凭据文件会被自动排除，不进索引。
- **飞书导入**：图片只记数量、附件只记文件名，正文才进索引。
